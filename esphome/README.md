# ESPHome: Inventor Matrix / Midea M-Thermal Modbus (read-only)

This template is for testing direct telemetry from an Inventor ATS04S / HU060S3
heat pump with a Wemos D1 mini (ESP8266) and an automatic-direction TTL-RS485
adapter. It defines only read sensors; it has no Modbus write entities or actions.

## Important compatibility note

The HU060S3 manual shows Modbus in system diagrams, and community documentation
for comparable Midea M-Thermal units describes Modbus RTU over the H1/H2 terminals
on the wired controller. This is not proof that every Inventor firmware exposes
the same register map. Treat the configuration as a read-only probe. If the
device does not answer or returns implausible values, stop and verify model,
bus, slave ID, and register mapping before changing anything.

## Bus connection

With the heat pump system isolated from the mains, inspect the **wired controller**
(the wall/user interface connected to the hydraulic unit). On compatible Midea
M-Thermal variants the documented RS485 pair is:

- Adapter A / A+ → H2
- Adapter B / B− → H1

Do not connect to the similarly labelled multi-unit Modbus / XYE terminals on the
main control board. Do not guess terminals from labels alone; verify H1/H2 on the
wired-controller PCB/manual before wiring. Keep the wired controller connected
to the hydraulic unit.

## TTL side to the D1 mini

Only if this exact adapter supports 3.3 V logic and supply:

- Adapter VCC → 3V3 on D1 mini
- Adapter GND → GND
- Adapter TXD → D1 mini D1 / GPIO5 (RX)
- Adapter RXD → D1 mini D2 / GPIO4 (TX)

The UART lines are crossed (adapter TXD goes to ESP RX and vice versa). Never
feed a 5 V TTL output into an ESP8266 pin. Check the actual board/chip and its
3.3 V rating before powering it. The configuration uses an automatic-direction
RS485 board and therefore does not reserve a GPIO for DE/RE.

Do not add a termination resistor automatically. First test a short cable;
only investigate termination if communication is unstable and the actual adapter
and bus wiring have been checked.

## Initial register probe

- Baud: 9600
- Format: 8 data bits, no parity, 1 stop bit (8N1)
- Initial slave ID: 1 (on comparable Midea units this depends on the address switch)
- Register map used as a starting hypothesis: DHW tank 115, outdoor air 107,
  water inlet 104, water outlet 105, compressor frequency 100, compressor runtime 122.

The register map is community-sourced for comparable Midea M-Thermal/OEM units,
not officially confirmed for this exact Inventor revision. Verify each value
against the wired controller/app.

## ESPHome setup

1. Copy `inventor_modbus_readonly.yaml` into the ESPHome add-on.
2. Define these in ESPHome's secrets file (keep secrets out of Git):
   - `wifi_ssid`
   - `wifi_password`
   - `inventor_modbus_api_key` (base64 32-byte key generated by ESPHome)
   - `inventor_modbus_ota_password`
   - `inventor_modbus_fallback_password`
3. Validate/compile before flashing.
4. First power and network-test the D1 mini by itself.
5. Only then connect the RS485 bus with the heat-pump system powered off.
6. Compare the resulting sensors with the official app/service parameters.

The current configuration has no control commands. Keep it that way until
read-only communication is confirmed.
